# D’ALEX ERP — Compartilhar a demonstração

## Arquivo único

Envie **`release/DALEX-ERP-V4-DEMONSTRACAO.html`** para quem vai avaliar. A pessoa baixa e abre no Microsoft Edge ou Google Chrome. Não precisa instalar Node.js, abrir terminal ou receber várias pastas.

O HTML contém exemplos fictícios e todos os estilos/códigos necessários. Cada navegador mantém sua própria avaliação, sem sincronizar os dados com outros avaliadores. Não insira dados reais.

Em **Perfil**, é possível testar Administrador, Operação e Consulta. Isso demonstra a matriz de acesso; não é login real. Para restaurar exemplos, selecione Administrador e abra **Configurações → Ambiente**.

## Link público

Acesse ou envie: **https://dalex-erp-v4-demonstracao.spicyclove20.chatgpt.site**.

A publicação foi confirmada pelo Sites e usa somente o HTML de demonstração, separado dos dados de desenvolvimento. Funciona por navegador, sem instalar ferramentas. Cada pessoa tem seus próprios exemplos e alterações locais, sem sincronização de dados com outros avaliadores.

O usuário autorizou acesso público com dados fictícios. Isso não autoriza publicar os registros locais do autor nem colocar o ERP definitivo em produção.

## Alternativa de hospedagem estática

`release/DALEX-ERP-V4-SITE.zip` contém os arquivos estáticos prontos, sem banco ou credenciais. Esse pacote pode ser enviado por upload único a um serviço estático, após configurar uma conta/plano gratuito adequado. Não é preciso instalar ferramentas no computador de quem testa.

Em celulares, use preferencialmente o link HTTPS. Visualizadores de arquivos de alguns aparelhos não executam JavaScript; isso não ocorre quando a aplicação é aberta como site no navegador.

## O que não compartilhar

Não é necessário enviar `node_modules`, código do projeto, chaves, `.env`, exportações pessoais ou `test-results`. Compartilhe o HTML ou o link da cópia de demonstração. O projeto real, quando autorizado, terá autenticação e dados compartilhados no servidor; esta cópia não possui essas funções.
